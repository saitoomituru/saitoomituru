## OND800 and performer sovereignty

OND800は成人向け専用機ではありません。配信技術としては中立な、汎用のライブ制作・撮影制御システムです。

目的は、演者本人が「撮られる側」に固定されず、演じながら自分のカメラ、音声、照明、配信先、復帰判断を握れるようにすることです。スポンサー保護より、ショーの継続と演者の判断権を上位に置きます。

実機試験は、技術SFW、歌唱、屋外ロケ、ダンス、工作、成人向け身体表現など、実際の過酷な現場を含みます。**コードとアーキテクチャは中立ですが、一部の試験映像・投稿はNSFWです。成人で、演者表現と工学評価を分けて閲覧できる方のみ進んでください。**
